Python 多功能智能助手

基于 Flask + LangChain 的 AI 对话系统
项目技术汇报

项目概述

一个支持语音对话、多角色切换、主题自定义、用户登录的全栈 AI 聊天应用

项目定位

基于 Web 的智能 AI 对话助手，个人效率工具兼具学习参考价值。采用浏览器/服务器架构，用户通过浏览器访问即可与 AI 进行自然语言对话

开发规模

40+ Python 文件 · 25+ API 接口 · 8 个蓝图模块 · 5 张数据表 · 约 1,900 行前端 JS · 从零构建的全栈项目

技术特色

策略模式多模型调度 · JSON-SSE 流式输出 · CSS 变量主题系统 · 双引擎 TTS 语音合成 · 用户数据完全隔离

应用场景

编程辅助 · 翻译润色 · 数据分析 · 知识问答 · 文档撰写 · 学习陪伴

系统架构

分层设计：路由层 → 服务层 → LLM 层 → 持久层

浏览器 (语音+粒子+SSE) → Nginx → Gunicorn+gevent │ ▼ Flask 应用工厂 ├── API 路由层 (8蓝图) auth/chat/conversation/role/voice/system/upload/background ├── 业务服务层 ChatService / ModelService / ToolService ├── LLM 调用层 (策略模式) DeepSeekClient / QwenClient / Memory ├── 中间件层 登录认证 / RateLimit(Redis) / Logger └── 数据模型层 User/Role/Conversation/Message/Background │ ▼ MySQL 8.0 + Redis 7.0

策略模式

BaseLLMClient 定义统一接口，DeepSeek/Qwen 各自实现。ModelService 工厂方法动态创建，新增模型无需改业务代码

应用工厂模式

create_app() 统一创建实例，根据 FLASK_ENV 加载开发/生产/测试配置，环境切换只需一个变量

注册表模式

ToolService._tools 字典管理工具，新增只需注册，不改调度逻辑。内置：计算器/数据分析/网络搜索

数据库设计

MySQL 8.0 utf8mb4, 5 张核心表

users (用户表) — 登录认证 + 数据隔离 id / username(UNIQUE) / password_hash(bcrypt) / phone / wechat_openid / qq_openid / nickname / avatar conversations (会话表) — 每次对话的元信息 id(UUID PK) / title / user_id(INDEX) / model / role_id / created_at / updated_at messages (消息表) — 每条对话消息 id(PK AUTO) / conversation_id(FK) / role(user/assistant) / content(TEXT) / tokens / created_at roles (角色表) — AI 角色定义 id / name(UNIQUE) / prompt / icon / is_builtin / user_id / created_at backgrounds (背景历史表) id / url / bg_type / mode / size / user_id / created_at

ORM 映射

SQLAlchemy db.Model 定义，Python 操作数据库无需手写 SQL。首次启动自动建表

Token 估算

中文字符×1.5 + 英文单词×0.3 + 数字×0.5。每条消息创建时自动计算

硬删除

删除会话时批量 delete messages 再 delete conversation，彻底清理不残留

核心流程：对话链路

从用户输入到 AI 流式回复的完整技术链路

1. 用户打字/语音 → 前端 POST /api/v1/chat/stream 2. Flask 接收 → ChatService.prepare_chat_context() 加载角色 System Prompt 从 MySQL 加载历史消息 (滑动窗口最近10轮) 组装消息列表: [System, History..., User] 3. ModelService.get_model_client() 获取客户端 4. DeepSeek/Qwen 流式返回 每个 chunk 用 json.dumps() 编码 5. SSE 推送 → marked.js 实时渲染 Markdown 6. 完成后: 持久化MySQL + Token统计 + TTS朗读

JSON-SSE 换行保护

chunk 用 json.dumps 编码，前端 JSON.parse 解码。解决 SSE 协议 \n\n 分隔符与数据内容冲突——这是本项目的核心技术创新

流式 Markdown

流式输出时每 chunk 调 marked.parse() 实时渲染，完成后 hljs 代码高亮。CDN 未加载时内置正则兜底

停止生成

AbortController + fetch signal。点击停止 → abort() 中断，已输出内容保留

语音功能 (TTS/STT)

3引擎11音色，浏览器语音输入 + 服务端语音合成

🎤 语音输入 (STT)

浏览器 SpeechRecognition API，免费。continuous=false 说完自动停止，实时填入输入框并自动发送。Ctrl+M 快捷键。配有麦克风诊断工具

🔊 火山引擎 TTS (8音色)

小源(BV700)/大夏(BV701)/清心(BV001)/知行(BV002)/知性(BV004)/彤彤(BV005)/小艾(BV402)/大庆(BV401)。Bearer Token 认证，POST 字节跳动 API，返回 base64 MP3 → Blob 播放

🔊 腾讯云 TTS (3音色)

智瑜(1001)/智美(1003)/智聆精品(1050)。tencentcloud-sdk-python-tts SDK，SecretId/Key 认证

发送前清洗 + 失败兜底

cleanForTTS() 去除 Markdown 语法(代码块/粗体/链接/标题)，只保留纯朗读文字。腾讯云限150字自动截断。API 失败自动切浏览器 speechSynthesis

主题系统

CSS 变量驱动 + 伪元素透明度 + 自定义背景

12 套预设主题

8套暗色（靛蓝/石墨/深海/松林/樱语/余烬/紫晶/矩阵）
4套亮色（石灰/薄荷/晴空/板岩）
每套定义14个CSS变量：背景/面板/卡片/文字/边框/气泡渐变/阴影

透明度分离技术

气泡/按钮/下拉框使用 ::after 伪元素承载背景渐变，opacity 只作用于伪元素。文字保持 100% 不透明。select 元素通过 JS 计算 rgba 实现仅背景透明

自定义背景

图片/视频 URL 输入，支持本地路径（通过 Flask 本地媒体代理）。全屏或仅聊天区显示。背景历史存储数据库，用户隔离

登录与用户隔离

Session 认证 + 5 种登录方式预留 + 数据完全隔离

已实现：密码登录

用户名+密码注册和登录，bcrypt 加密存储密码。注册时自动分配昵称。Session 会话管理，Flask before_request 中间件保护所有路由

预留：手机/微信/QQ

手机验证码登录（测试验证码 123456）、微信 OAuth 扫码、QQ OAuth 扫码。UI 和 API 均已完成，因需要企业营业执照认证暂不可用

数据隔离机制

每个用户只能看到自己的：对话历史、自定义角色、背景历史。内置角色全局共享。所有 API 通过 session['user_id'] 过滤数据。后端默认值从 'anonymous' 改为从 session 读取

前端技术亮点

分层原则

每层只依赖下一层：API → Service → LLM/Model。上层不关心下层实现细节

蓝图注册

每个功能模块独立蓝图，统一挂载 /api/v1 前缀。新增功能只需添加新蓝图文件并注册

配置分离

.env 存密钥，settings.py 三环境配置类。.gitignore 排除 .env 防止泄露
